# TUDelftBK_storymap｜台夫特建築系故事地圖

從運河邊的建築學程到設計名校：台夫特理工大學建築學院（Faculteit Bouwkunde）1842–2026年的發展史，以De Stijl風格派的視覺語言製作成中英雙語故事地圖。

- 故事地圖：<https://yunching0513.github.io/TUDelftBK_storymap/>（[index.html](index.html)）
- 十位建築師簡介：<https://yunching0513.github.io/TUDelftBK_storymap/architects.html>（Markdown版見[architects/](architects/README.md)）

## 內容

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 中英雙語故事地圖，十二個站點，捲動時地圖在台夫特街區與荷蘭全國之間移動 |
| `architects.html` | 十位與台夫特建築系相關的建築師：生平、代表作品與參考資料 |

## 十位建築師

1. [古格爾（Eugen Gugel，1832–1905）](architects/01-eugen-gugel.md)：台夫特第一位建築教授（1864–1902）
2. [貝拉赫（Hendrik Petrus Berlage，1856–1934）](architects/02-hp-berlage.md)：荷蘭現代建築之父；1905年在台夫特演講
3. [格蘭普雷・莫利耶（Marinus Jan Granpré Molière，1883–1972）](architects/03-granpre-moliere.md)：台夫特教授（1924–1953）；台夫特學派創始者
4. [杜伊克（Jan Duiker，1890–1935）](architects/04-jan-duiker.md)：台夫特出身的「新建築」先驅
5. [范登布魯克（Jo van den Broek，1898–1978）](architects/05-jo-van-den-broek.md)：台夫特建築教授（1947–1964）
6. [貝克瑪（Jaap Bakema，1914–1981）](architects/06-jaap-bakema.md)：台夫特教授（1963–1981）；Team 10核心成員
7. [范埃斯特倫（Cornelis van Eesteren，1897–1988）](architects/07-cornelis-van-eesteren.md)：台夫特都市計畫教授（1947–1967）；CIAM主席（1930–1947）
8. [凡艾克（Aldo van Eyck，1918–1999）](architects/08-aldo-van-eyck.md)：台夫特教授（1966–1984）；Team 10共同創立者
9. [赫茲伯格（Herman Hertzberger，1932–）](architects/09-herman-hertzberger.md)：台夫特教授（1970–1999）；Berlage研究院創辦人
10. [韋伯（Carel Weeber，1937–2025）](architects/10-carel-weeber.md)：台夫特教授（1970–2003）
