# 03｜沃芬斯伯格（Grada Wolffensperger，1887–1965）

**台夫特第一位女性建築工程師（1917）**

## 台夫特第一位女性建築工程師，卻沒有留下任何一棟建築

![目前沒有任何可確認由她設計的建築存世，此處以風格派構成圖代替。](../assets/img/wolff-comp.jpg)

*目前沒有任何可確認由她設計的建築存世，此處以風格派構成圖代替。*

沃芬斯伯格（Grada Wolffensperger）1887年生於海牙，1910年通過台夫特技術高等學院的預科考試，1915年通過建築工程師候選人考試，1917年完成學業，成為台夫特第一位女性建築工程師；當時的報紙稱她為荷蘭的「第一位女建築師」（eerste bouwmeesteres）。依據Smeets-Klokgieters（2017）的研究，1946年以前，荷蘭只有約二十位女性取得建築學位，而當時台夫特是全國唯一的大學層級建築教育。

畢業後，她在哈勒姆市公共工程局擔任助理建築師數年，1922年曾擔任荷蘭建築師協會（BNA）的考試委員，但1924年之後似乎就不再執業。至今沒有任何一棟可以確認由她設計的建築，留下來的只有1915年在艾丹（Edam）畫下的兩張鉛筆素描。1965年，她在海牙兒時的家中辭世。

筆者認為，沃芬斯伯格被遺忘的原因，恐怕不在於她不夠優秀，而在於建築史習慣以「作品」來記住建築師。**當一位女性在制度上取得了資格，卻沒有機會留下作品時，她在建築史上的位置也跟著消失。**這正是本頁把她放進來的理由。
